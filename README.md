# MATH840, фінальний проєкт: прогноз генерації на 48 годин

Валентин Мастицький

Ноутбук `MASTYTSKYI_final_project.ipynb` будує файл `MASTYTSKYI_project.csv` з точковим прогнозом і 95% інтервалом на 48 годин після кінця `train.csv`. Звіт лежить у `report.pdf`.

## Файли

| файл | вміст |
|---|---|
| `MASTYTSKYI_final_project.ipynb` | код: шаблон курсу з моделлю, backtest і записом файлу |
| `report.pdf` | звіт з відповідями на чотири питання |
| `train.csv`, `weather_forecast.csv` | дані курсу |
| `backtest/` | скрипти перевірки на 600 вікнах, з яких отримані числа у звіті |

## Запуск

Відкрити `MASTYTSKYI_final_project.ipynb` у Colab або Jupyter і запустити всі клітинки згори донизу. Перша клітинка встановлює бібліотеки (`chronos-forecasting`, `timesfm`). У Colab ноутбук попросить завантажити `train.csv` і `weather_forecast.csv`, локально файли мають лежати поруч із ноутбуком. Достатньо CPU, повний запуск разом із backtest на 20 вікнах займає приблизно 10–20 хвилин. Результат збігається з поданим файлом.

## Перевірка (backtest)

Скрипти в `backtest/` запускаються з кореня репозиторію і потребують `pip install "chronos-forecasting>=2.0" "timesfm[torch]" scikit-learn pyarrow matplotlib`. Кожен працює 5–30 хвилин на CPU і зберігає прогнози у файл parquet.

| скрипт | що робить |
|---|---|
| `bt.py` | Chronos-2 з погодою на 600 вікнах (модель Session 1): `python backtest/bt.py bt600.parquet final.parquet` |
| `solar.py` | те саме з колонками сонця |
| `tf3_bt.py` | TimesFM 3 з погодою і сонцем |
| `bt3.py` | Chronos-2 без погоди і на логарифмі |
| `noisy.py` | Chronos-2 з шумом у погоді, для вибору ширини інтервалу |
| `ctx.py` | інша довжина контексту |
| `ft.py` | донавчання Chronos-2 (LoRA) |
| `comb.py`, `pstack.py`, `stack.py` | комбінації моделей і бустинг поверх Chronos |
| `summarize.py` | таблиці і графіки для звіту з файлів parquet |
