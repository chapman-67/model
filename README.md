Валентин Мастицький

Ноутбук `MASTYTSKYI_final_project.ipynb` робить файл `MASTYTSKYI_project.csv`: прогноз і 95% інтервал на кожну з 48 годин після кінця `train.csv`. Звіт лежить у `report.pdf`.

## Файли

| файл | що в ньому |
|---|---|
| `MASTYTSKYI_final_project.ipynb` | шаблон курсу з моделлю, перевіркою і записом файлу |
| `report.pdf` | звіт з відповідями на чотири питання |
| `train.csv`, `weather_forecast.csv` | дані курсу |
| `backtest/` | скрипти перевірки на 600 вікнах, з них узяті числа у звіті |

## Запуск

Відкрийте `MASTYTSKYI_final_project.ipynb` у Colab або Jupyter і запустіть усі клітинки згори донизу. Перша клітинка ставить бібліотеки `chronos-forecasting` і `timesfm`. Colab попросить завантажити `train.csv` і `weather_forecast.csv`, а локально файли мають лежати поруч із ноутбуком. Вистачить CPU. Увесь запуск разом із перевіркою на 20 вікнах триває 10–20 хвилин і дає той самий файл, що я подав.

## Перевірка (backtest)

Скрипти з `backtest/` запускайте з кореня репозиторію. Їм потрібні `pip install "chronos-forecasting>=2.0" "timesfm[torch]" scikit-learn pyarrow matplotlib`. Кожен працює 5–30 хвилин на CPU і зберігає прогнози у файл parquet.

| скрипт | що робить |
|---|---|
| `bt.py` | Chronos-2 з погодою на 600 вікнах (модель Session 1): `python backtest/bt.py bt600.parquet final.parquet` |
| `solar.py` | те саме з колонками сонця |
| `tf3_bt.py` | TimesFM 3 з погодою і сонцем |
| `bt3.py` | Chronos-2 без погоди і на логарифмі |
| `noisy.py` | Chronos-2 із шумом у погоді, щоб вибрати ширину інтервалу |
| `ctx.py` | інша довжина контексту |
| `ft.py` | донавчання Chronos-2 (LoRA) |
| `comb.py`, `pstack.py`, `stack.py` | суміші моделей і бустинг поверх Chronos |
| `summarize.py` | таблиці й графіки для звіту з файлів parquet |
